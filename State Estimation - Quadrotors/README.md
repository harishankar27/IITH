# State Estimation - Quadrotors

This project implements state estimation techniques for quadrotors based on a detailed nonlinear dynamics model.

## Quadrotor Dynamics Modeling

The quadrotor dynamics are modeled using Newton-Euler equations describing translational and rotational motion, including forces and torques generated by rotor thrusts and gyroscopic effects. The states include position, velocity, roll, pitch, yaw, and angular velocities, transformed between body and inertial reference frames. A linearized model around hover condition is also used for estimator design.

## Main Code

- **State_Estimation_Quadrotor_Dyanmics.m**: MATLAB implementation of the nonlinear quadrotor dynamics model and state estimators like the Kalman Filter, Unscented Kalman Filter, and Moving Horizon Estimator.
- The script simulates estimators with noisy sensor data and visualizes estimation accuracy and errors.

Run the MATLAB script to reproduce simulations and compare estimator performance.
